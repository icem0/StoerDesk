## Conventions (short form, details in `specs/00-conventions.md` and `PLAN.md` §3/§4.1)

- Language: code, comments, logs and developer documentation in English; user-facing text
  only through i18n keys (`de` default, `en` complete).
- Errors: `{ code, params }`, never translated text in logs or payloads; logging: Pino,
  structured, no PII in plain text.
- IDs: UUID (UUID v7 as database default), timestamps are server time; tests: Vitest per
  workspace, Playwright for E2E (WP-M1-12).
- Commits: Conventional Commits, `Signed-off-by` (DCO), one WP = one commit = one tag.

API integration tests need a real Postgres 16 (`TEST_DATABASE_URL`); CI provides it as a service, without a reachable local database they skip and `npm run check` stays green. The Docker smoke test runs only in the CI job `docker-smoke`, because this development container has no Docker — there `sh -n scripts/docker-smoke.sh` plus `npm run check` is all that can be proven locally. **Phase 5 started**: the split WP-M5-01 … 09 is planned in `work-packages/m5/`; **WP-M5-01** is implemented — the Dexie v2 `internal_actions` queue (oldest-first replay on app start and `online`, `client_uuid` idempotency keys, `pendingWrites`) waits for its endpoints (WP-M5-02 … 04).
