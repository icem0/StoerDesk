## Conventions (short form, details in `specs/00-conventions.md` and `PLAN.md` §3/§4.1)

- Language: code, comments, logs and developer documentation in English; user-facing text
  only through i18n keys (`de` default, `en` complete).
- Errors: `{ code, params }`, never translated text in logs or payloads; logging: Pino,
  structured, no PII in plain text.
- IDs: UUID (UUID v7 as database default), timestamps are server time; tests: Vitest per
  workspace, Playwright for E2E (WP-M1-12).
- Commits: Conventional Commits, `Signed-off-by` (DCO), one WP = one commit = one tag.
