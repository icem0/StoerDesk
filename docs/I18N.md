# I18N

> Platzhalter gemäß `work-packages/m1/10-ci-workflow.md` (WP-M1-10).
> Details in `specs/00-conventions.md` (§0.1, §2a).

## Sprachen

| Sprache       | Rolle                                   | Ort                                   |
| ------------- | --------------------------------------- | ------------------------------------- |
| Deutsch (de)  | Default, Referenz für UI-Texte          | `apps/web/src/i18n/locales/de/*.json` |
| Englisch (en) | Referenz-Sprache, muss vollständig sein | `apps/web/src/i18n/locales/en/*.json` |

## Namespaces (Web)

`common`, `errors`, `validation`, `ticket`, `object`, `oncall`, `stats`, `settings`.

## Namespaces (Shared/Server)

- `packages/shared/src/i18n/server.{de,en}.json` — serverseitige Texte (Fehlermeldungen, Labels).
- `packages/shared/src/i18n/seed.{de,en}.json` — Texte für Seed-Daten.

## Regeln

- UI-Texte ausschließlich über i18n-Keys, keine Literal-Strings (Lint: `i18next/no-literal-string`).
- Fehler werden als `{ code, params }` übertragen, nicht als übersetzter Text.
- Schlüssel-Konvention: `namespace.section.element`, camelCase für Parameter (`{{count}}`).
- `npm run i18n:check` prüft Key-Parität zwischen de und en sowie referenzierte Schlüssel.
