## Locales

| Locale         | Role                              | Location                              |
| -------------- | --------------------------------- | ------------------------------------- |
| German (`de`)  | Default and reference for UI text | `apps/web/src/i18n/locales/de/*.json` |
| English (`en`) | Must be complete, no missing keys | `apps/web/src/i18n/locales/en/*.json` |

## Namespaces (web)

`common`, `errors`, `validation`, `ticket`, `object`, `oncall`, `stats`, `settings`.
Only `common` carries real keys so far, the rest are intentionally empty. A new
namespace file must also be registered in `apps/web/src/i18n/index.ts`, otherwise the
web bundle never loads it.

## Namespaces (shared/server)

- `packages/shared/src/i18n/server.{de,en}.json` — server-side text (error messages,
  labels), read through `t(locale, key, params)` in `packages/shared/src/i18n/t.ts`.
- `packages/shared/src/i18n/seed.{de,en}.json` — localized text for seed data, so
  seeds hold no German string literals.

## Rules

- UI text only through i18n keys, never literal strings (lint rule
  `i18next/no-literal-string`).
- Errors travel as `{ code, params }`, never as translated text in API payloads or
  logs.
- Key convention: `namespace.section.element`, parameters in camelCase (`{{count}}`).
- `npm run i18n:check` verifies the de/en key parity of the web locales and the shared
  server/seed files, and that every `t()` key referenced in `apps/web/src` exists.
