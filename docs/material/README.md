# Material

Ablage für gelieferte Quelldokumente (Ursprungsmaterial, nicht Teil des Codes).

| Ordner | Inhalt |
| --- | --- |
| `material/` | Originaldokumente, die geliefert wurden (z. B. Pflichtenheft, Notizen) |
| `notizen/` | Arbeitsnotizen, Entscheidungen, offene Punkte |

Die Spezifikation wird daraus in `specs/` gespiegelt (siehe `scripts/split-spec.mjs`).
Originale bleiben unverändert, abgeleitete Inhalte tragen die Kapitelzuordnung aus
`specs/README.md`.
