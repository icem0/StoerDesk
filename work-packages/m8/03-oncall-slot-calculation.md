## Task

1. Add `date-fns-tz` to `packages/shared` (`PLAN.md` §4) and export the pure
   module from `packages/shared/src/index.ts`.
2. Implement `resolveOncallSettings` with per-key validation and the defaults of
   `specs/04-oncall.md` §4a.1; an invalid value falls back to its default.
3. Implement `generateOncallSlots`: find the first local `weekStartWeekday` at
   `startTime` on or after `from`, then emit one slot per `durationDays` while
   the start is before `to`; `endsAt` is the same local wall-clock time
   `durationDays` later. Convert both ends from `Europe/Berlin` to UTC with
   `date-fns-tz`.
4. Add unit tests for a normal 168-hour week, the spring week of 2026-03-23
   (167 h), the autumn week of 2026-10-19 (169 h), a non-Monday `week_start_weekday`,
   a non-07:00 `start_time`, a `duration_days` other than 7 and a range with no
   complete slot.

## Non-goals

- No database, service or route.
- No timezone per pool; `Europe/Berlin` is fixed (ADR-0011).
- No DST handling in the web UI; it consumes UTC from the API.
